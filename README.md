# மகளிர் உரிமைக் குரல் | Magalir Urimai Kural

> உங்கள் உரிமை... உங்கள் குரலில்...

Magalir Urimai Kural is an AI-assisted web application designed to help women understand government schemes and services through simple Tamil voice and text interaction.

## Features

- Tamil-first user interface
- Voice-based interaction
- Simple text-based chat
- Government scheme discovery
- Scheme details
- Eligibility guidance
- Required documents
- Application guidance
- Tamil and English interface
- Mobile and desktop responsive design

## Technology

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Responsive Web Design
